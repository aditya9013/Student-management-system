# 🎓 Student Management System

## 📌 Description
This is a Java console application that uses Object-Oriented Programming (OOP) concepts to manage student records. It allows basic CRUD (Create, Read, Update, Delete) operations.

## 🚀 Features
- Add Student
- View All Students
- Delete Student
- Search Student by ID
- Update Student Details
- Input Validation & Exception Handling

## 🛠️ Technologies Used
- Java
- OOP (Classes & Objects)
- ArrayList
- IntelliJ IDEA

## ▶️ How to Run
1. Open the project in IntelliJ IDEA
2. Run the `Main.java` file
3. Follow the menu options in the console
