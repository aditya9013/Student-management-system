# 🎓 Student Management System

## 📌 Description
This is a Java-based console application that uses Object-Oriented Programming (OOP) concepts to manage student records.  
The system allows users to perform basic CRUD (Create, Read, Update, Delete) operations efficiently.

---

## 🚀 Features
- ➕ Add Student  
- 📋 View All Students  
- ❌ Delete Student  
- 🔍 Search Student by ID  
- ✏️ Update Student Details  
- ⚠️ Input Validation & Exception Handling  

---

## 🛠️ Technologies Used
- Java  
- OOP Concepts (Encapsulation, Classes & Objects)  
- ArrayList  
- IntelliJ IDEA  

---

## ▶️ How to Run
1. Open the project in IntelliJ IDEA  
2. Run the `Main.java` file  
3. Follow the menu options in the console
